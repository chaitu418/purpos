# Purpos

A Bengaluru-first website for meaningful business and professional connections.

## Current status

The first local React landing page is working.

It includes:

- Purpos branding and Bengaluru Beta label
- Landing-page message
- “Create your purpose” call-to-action button
- “Explore connections” call-to-action button
- Responsive visual design
- Local development server using Vite

## Technology used so far

- React — user interface
- Vite — local development server and production build
- CSS — styling and responsive design
- Git — project version history
